# Rex Strength Lab

Three physics and anatomy tools built around Rex, an indestructible 10 ft dinosaur, and his boyfriend Ollie, a bull-man who is just as strong and just as indestructible.

| Project | What it does | Live page |
|---|---|---|
| [`rex-strength-lab/`](rex-strength-lab/) | Set Rex's strength from world-record human to infinite and see what lifts, throws, jumps, punches, sprints and pulls do to him, the object, the ground and the air. Any density from plush to black hole. Two-player tests with Ollie: arm wrestling, wrestling, a game of catch, and unstoppable force vs immovable object. | https://claude.ai/artifact/YFpbHtX8tM2Qwffd6znbZP |
| [`build-calculator/`](build-calculator/) | Pick a build and a height to estimate weight and seven tape girths (chest, waist, flexed arm, forearm, thigh, calf, neck) for 55 builds: US Army survey percentiles, US adults, bodybuilders, strongmen, comic characters, and Rex and Ollie. | https://claude.ai/artifact/9aKMVmtGqXXT2kGMYvZb5E |
| [`build-comparison/`](build-comparison/) | 49 men's builds on one scale of muscle level with height taken out, as silhouettes and score ranges: ordinary men, the top of the human record, comic giants, Rex and Ollie, and the empty stretches between, up to a solid ball of muscle. Also measures a character from an A-pose model sheet. | https://claude.ai/artifact/DBtZrixDeZnvRwDhZMsCDn |

Every number on every page is either sourced or labelled an estimate. Each folder has its own README with build and test steps, the sources, the review history and the known limits.

All three pages are single self-contained HTML files (`dist/index.html`) built with Node and Python, with no runtime dependencies.
